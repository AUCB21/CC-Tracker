# Self-hosted fonts

Downloaded from Google Fonts (fonts.gstatic.com), latin subset, variable
weight axis, because `next dev` was intermittently failing to fetch them at
build time via `next/font/google` and silently falling back to Arial.

- `public-sans-latin-wght.woff2` - Public Sans - https://fonts.gstatic.com/s/publicsans/v21/ijwRs572Xtc6ZYQws9YVwnNGfJ4.woff2 - SIL Open Font License 1.1 (https://openfontlicense.org), copyright its respective authors.
- `familjen-grotesk-latin-wght.woff2` - Familjen Grotesk - https://fonts.gstatic.com/s/familjengrotesk/v11/Qw3GZR9ZHiDnImG6-NEMQ41wby8WbHoEjw.woff2 - SIL Open Font License 1.1 (https://openfontlicense.org), copyright its respective authors.
- `geist-mono-latin-wght.woff2` - Geist Mono - https://fonts.gstatic.com/s/geistmono/v6/or3nQ6H-1_WfwkMZI_qYFrcdmg.woff2 - SIL Open Font License 1.1 (https://openfontlicense.org), copyright its respective authors.
